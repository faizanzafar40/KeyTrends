    What this records. KeyTrends stores counts only — how many times each key was pressed on a given day, click and scroll totals, cursor travel, and which application had focus. It never stores the order you pressed keys in, so the data cannot reconstruct anything you typed. Everything stays in a local SQLite file on this PC; nothing is uploaded anywhere.
